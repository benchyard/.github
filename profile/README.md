# Benchyard

**People and coding agents, working toward a reviewed result.**

We build composable tools for shared tasks, self-hosted delivery, persistent cloud
environments and test evidence. Start small; use your existing Git host or agent.

[Explore the stack](https://benchyard.github.io/stack/) · [Working example](https://github.com/benchyard/stack/blob/main/docs/use-case.md)

![Product architecture](https://raw.githubusercontent.com/benchyard/stack/main/docs/assets/stack.svg)

| Product | Purpose |
|---|---|
| [Benchyard Console](https://hero.benchyard.com/) | Shared work and agent execution (repository currently private) |
| [Acahti](https://github.com/lpythu/acahti) | Git, checks, packages and MCP identity |
| [Acahti Plugin](https://github.com/lpythu/acahti-plugin) | Cursor and Codex integration guidance |
| [Skheri](https://github.com/benchyard/skheri) | Persistent workspaces and preview before commit |
| [Argos](https://github.com/lpythu/argos) | Once/soak checks and reviewable evidence |
| [Argos Dash](https://github.com/lpythu/argos-dash) | Team run browser |
| [Argos Pack](https://github.com/benchyard/argos-pack) | Portable executable examples |

Acahti, Skheri and Argos work independently. The official Benchyard Worker retains
its separate proprietary binary license; the product group is not an assertion
that every component is open source. See each repository for its license and scope.
